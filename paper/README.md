# The paper's integration points

This repository produces everything a LaTeX paper needs. A draft now exists, at [`draft/paper.tex`](draft/paper.tex) (compiled: [`draft/paper.pdf`](draft/paper.pdf)), built from the outline in the originating repository's `tmp/gsr/paper-outline-record-conditioned-gravity.md`. `make paper` recompiles it from the current state of the repository's own results. These are the integration points the draft uses, and nothing else:

## Numbers

```latex
\input{numbers.tex}
```

Defines one command per quoted value (`\fEtaHalfRuleI`, `\resolvabilityOsmium`, `\tMinPublishedTorsionDays`, ...), generated by `rcg.emit.macros()` from `results/check.json` and `results/realistic.json`. A regenerated result changes the paper's numbers without touching the `.tex` source. The full list is `src/rcg/emit.py`'s `macros()` function; every name there is a command name here.

## Tables

```latex
\input{tables/discriminators.tex}
\input{tables/platforms.tex}
\input{tables/feasibility-gate.tex}
```

`booktabs`-style, generated by `rcg.emit.write_tables_tex()`.

## Figures

```latex
\includegraphics{figures/check-2-no-signalling.pdf}
\includegraphics{figures/realistic-2-resolvability.pdf}
% ... see build/figures/ for the full set, each also as .png
```

Generated at a width suited to a two-column paper (`figsize` in `experiments/*/figures.py`); regenerate with `make figures`.

## References

```latex
\bibliography{refs}
```

`refs.bib`, generated from `data/references.yaml` by `rcg.emit.write_refs_bib()`, so the paper and this repository's own documentation cite identically.

## Building the feed

```
make latex figures
```

writes everything above into `build/latex/` and `build/figures/`. `test/minimal.tex` in this directory is a minimal document that `\input`s and `\includegraphics`s every one of them, kept only to prove the feed compiles; it is not a draft of the paper and never became one.

## Building the draft

```
make paper
```

runs `make latex figures` and then `pdflatex`/`bibtex`/`pdflatex`/`pdflatex` on `draft/paper.tex`, writing `draft/paper.pdf`. Requires a LaTeX toolchain with `revtex4-2`, `siunitx` is NOT used (a known `p{}`-column incompatibility with this toolchain's `array`/`siunitx` versions -- see the draft's git history if revisiting this) -- scientific notation is set as plain text (`2.22e-16`) throughout rather than `\num{...}`-typeset, a deliberate choice, not an oversight.
